MindToo

Help

Installing MindToo, looking after your memory, and taking it with you.

Installing

Install it on Windows.

Download

Download the installer from the MindToo page and run it. It installs for you alone, with no administrator rights needed, and opens MindToo when it finishes.

Checking your download

The installer is signed by PrivateAI, Belfast Ltd through Microsoft’s signing service, so Windows names the publisher when it asks whether to run it. If Windows says the publisher is unknown, the file is not ours: do not run it.

To be sure your download is the one we published, open PowerShell in your Downloads folder and run Get-FileHash .\MindToo-Setup-1.14.0.exe. The result should match the SHA-256 published with the release: 1d07c4701d959f20f12356d67efccac16c9abf5e34b556d5db62fb8f411a73d5.

Connect your assistants

In MindToo, open Assistants. It lists the ones it finds on your computer; connect each one you use.

Check it is working

On the Assistants screen, press Check, then send a message in that assistant. MindToo shows your message arriving, or says plainly if nothing came.

Your memory

Where it lives, and how to keep it.

Where it lives

In the .mindtoo folder in your Windows user folder, as one file, mindtoo.db. Nothing is kept anywhere else.

Export

Export everything to a single file whenever you like, with Export everything in the app. Export never locks, trial or not.

Backups

Make a backup from Settings at any time. A backup is a consistent copy, and restoring one brings back only what is missing.

Switching capture off

Pause MindToo for every assistant from the app, or set one assistant’s access to read-only or none. While it is paused, nothing new is kept.

Keeping things private

Mark a topic or a conversation private, and no assistant can see it. You still can.

Deleting

Only you can delete for good, in the app. Deleting a conversation asks you first.

Leaving

Uninstalling.

The app

Uninstall MindToo from Windows Settings, under Apps. Disconnect your assistants in MindToo first, so their settings are tidied too.

Your memory

Uninstalling leaves your memory where it is, in the .mindtoo folder, so nothing is lost by accident. Export it first if you want a copy, then delete the folder yourself if you want it gone.
