MindToo manual · Chapter 6

The command line, and when something is wrong.

Everything the window does, the mindtoo command does too. Then the faults we have seen, and what fixes each.

Commands

The mindtoo command.

Open a terminal and type mindtoo on its own for this list.

mindtoo setup [assistant]

Connect MindToo to your assistants: all the ones it finds, or one by name (claude-desktop, claude-code, codex, cursor, gemini, windsurf).

mindtoo view

Open your memory in the browser, on this computer only.

mindtoo status

What is stored, which assistants use it, and the licence.

mindtoo recall "question"

Search your memory from the terminal.

mindtoo activate KEY

Activate your licence.

mindtoo export [file]

Save everything to a JSON file. Always allowed.

mindtoo import FILE

Bring in a MindToo export.

mindtoo testimony

List the earlier conversations Claude Code, Codex and Gemini CLI hold on this computer; mindtoo testimony APP [--folder NAME] brings them in; mindtoo testimony export FILE brings in a data export from the Claude app or ChatGPT (the zip, or conversations.json).

mindtoo handover FILE [--from chatgpt|claude|gemini] [--keep]

What another assistant remembers about you: shows each statement; with --keep, keeps the ones MindToo does not already hold.

mindtoo purge ID --yes

Permanently delete one memory. Only you can do this.

mindtoo embeddings builtin

Search by meaning with the model built into the MindToo app; mindtoo embeddings URL MODEL uses your own local embeddings server instead, such as Ollama.

mindtoo reindex

Add embeddings to memories that lack them.

mindtoo serve [--as NAME]

The MCP server itself. Your assistants run this; you rarely need to.

When something is wrong

The faults we have seen.

Nothing arrives from an assistant

Press Check it and read what it says: it names the assistant and what to do. Nearly always the assistant has not been restarted since it was connected. Claude Code: a new session. Codex: quit and reopen, accept the hooks. The Claude app: add the MindToo skill in Claude (Settings, Capabilities, Skills), then a new chat. Gemini CLI: a new session. Cursor and Windsurf: quit and reopen.

An assistant "needs attention"

Its settings changed under MindToo (an update, or another tool rewrote them). Press Repair on the Assistants screen, restart the assistant, press Check it.

The window says MindToo is locked

Enter your passcode. There is no reset by email, because there is no account: the passcode is yours alone, so keep it where you keep such things.

The trial has ended

Reading, search and export all still work. New memories wait until you add a licence under Settings.

The licence asks to be checked

It has been more than 30 days since the shop last confirmed it. Connect to the internet once; it is checked and carries on.

Search by meaning is "words only for now"

The MindToo app is not running, so the built-in model is not available to the terminal. Open MindToo, or point MindToo at your own embeddings server.

You moved, reinstalled or updated

Your memory is the file in the .mindtoo folder of your Windows user folder. Updating or uninstalling MindToo leaves it where it is. To move it to another computer, export everything and import it there, or copy the folder.

Something else

Write to support@privateai.ltd with what you did, what you expected, and what MindToo said. The Activity screen often holds the answer: it shows what changed, and who changed it.
