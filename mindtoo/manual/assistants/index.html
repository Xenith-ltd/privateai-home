MindToo manual · Chapter 3

Your assistants.

MindToo finds the assistants on your computer and connects them for you. Each one needs a restart to start keeping; after that, they share one memory.

Watch it

Each assistant

What each one needs.

Claude Code

Connect, then start a new session: hooks load when a session starts. Each message you send and each reply is kept from then on.

Codex

Connect, then quit and reopen Codex. If it asks you to trust MindToo’s hooks, accept. Enter keeps your words; the reply is kept once it is complete.

The Claude app

MindToo hands the Claude app its skill and plugin. Make sure the MindToo skill is added in Claude (Settings, Capabilities, Skills), then start a new chat; each turn is kept.

Gemini CLI, Cursor, Windsurf

Connect, then start a new Gemini CLI session, or quit and reopen Cursor or Windsurf. Each keeps in its own format; MindToo reads all of them.

Not listed?

MindToo lists an assistant when it finds it installed on this computer. Install it, then return to Assistants: it appears as soon as it is there.

Advanced

All assistant controls.

The Assistants screen keeps the first working path clear. Switch to Advanced for connection details, access choices and the migration tools.

Access

Give each assistant full access, read-only access, or none. Read-only lets it recall but not remember; none refuses it entirely. Assistants that have used MindToo before are listed too, with their last use and their access.

Repair

When an assistant’s connection needs attention, the screen says so. Press Repair, restart that assistant, then press Check it.

Disconnect

Disconnecting restores the settings MindToo backed up when it connected. Your memory is untouched.

Earlier conversations and memories

Your assistants already hold conversations from before MindToo. Bring in what Claude Code, Codex and Gemini CLI hold on this computer, and the data exports of the Claude app and ChatGPT. Nothing is read until you choose, and anything brought in twice, or already kept, is held once.

What they remember about you

See what ChatGPT, Claude or Gemini have remembered about you, one statement at a time, and keep the ones you want. The preview keeps nothing by itself.

Agents

Named agents inside your assistants, such as a reviewer in Claude Code, each keep their record under their own name. A message to an agent reaches only that agent, and a folder can belong to one. An agent appears when its app names it, when it names itself, when you tie a conversation or a folder to it, or when you bring it in from Claude Code or Codex.

Skill packs

Extra skills that put what MindToo keeps to work. Add one to Claude Code and Codex from here; for the Claude app, get the file and upload it in Claude under Settings, Capabilities, Skills.
