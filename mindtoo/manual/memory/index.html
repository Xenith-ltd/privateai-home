MindToo manual · Chapter 2

Your memory.

Two kinds of record, kept on your computer: everything said, and the things worth keeping from it.

What is kept

Conversations and memories.

Conversations

Every message you send and every reply you get, kept as it happens, in each connected assistant. The Conversations screen lists them, with search by meaning as well as by words. Open one to read it whole, name it, or mark it private.

Memories

The facts, decisions, preferences and tasks that matter, kept as single statements for every assistant to use. Assistants add them as you work; you can add one yourself with Add a memory. The Memories screen filters them: All, Standing, Open tasks, Archived, Earlier versions.

Handed over first

Before an assistant answers you, MindToo hands it what it holds that bears on your message, from every assistant you use. Tell one of them something, and the others can find it.

Standing

A pinned memory is a standing instruction: every assistant sees it at the start of every conversation. Pin the things you would otherwise repeat.

Open tasks

A memory kept as a task stays under Open tasks until it is done, and assistants see what is open when a conversation starts.

Asking

Ask your memory a question.

By meaning

Type a question in the box at the top. MindToo finds what you meant even when none of your words match, using a small model that runs inside the app, on this computer.

Honest about what it knows

When nothing it holds answers the question, it says so plainly, rather than guessing. An assistant asking the same question gets the same honesty.

From the terminal

mindtoo recall "your question" asks the same question from a command line. Chapter 6 has every command.

Changing things

Correct, archive, delete.

Corrected everywhere

Tell any assistant it has something wrong, or edit the memory here, and the correction replaces it for all of them. The old version stays under Earlier versions, so nothing is lost by being corrected.

Archive

An assistant, or you, can archive a memory: it leaves recall and the lists, and stays under Archived, where you can restore it. An assistant cannot destroy anything.

Delete

Deleting for good is yours alone, from the app or with mindtoo purge, and MindToo asks you first. Deleting a conversation asks too.

Messages between assistants

Assistants can leave messages for each other, and for named agents, through MindToo. The Messages screen shows them. A message to an agent reaches only that agent.

Activity

Everything that has changed, by whom. Your own actions show as "person"; an assistant’s show under its name.
