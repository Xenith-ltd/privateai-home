MindToo manual · Chapter 4

Private by construction.

MindToo keeps your memory on your computer. These controls decide which of your assistants may see what, and when; what goes online is set out below.

Watch it

The Privacy screen

Pause, private, lock.

Pause

While paused, every assistant is told memory is paused, and nothing is read or written. You still see everything here. Unpause when you are ready.

Private topics

Memories in a private topic never reach any assistant: not in recall, not in lists, not in the start-of-conversation summary. You still see them. Conversations are not filed by topic: to keep a conversation from every assistant, open it in Conversations and mark it private.

Passcode and lock

Set a passcode, and locking stops your assistants and this window from using your memory until you enter it. The lock screen says "MindToo is locked". Locking does not encrypt the memory file itself, so keep your Windows account protected too.

What leaves this computer

MindToo keeps your memory on your computer and searches it locally by default. It contacts Polar to activate and re-check your licence, and a wallet key’s provider when you press Test. If you configure an embeddings server, text is sent to that server. Connected assistants can receive the context you permit; their processing follows their own provider and settings. There is no MindToo account or MindToo cloud.

Every address MindToo’s own code can reach

The shop, api.polar.sh: your licence key, once when you activate and then at most once a week; if the shop cannot be reached, a licence keeps working for 30 days. The checkout page, buy.polar.sh, which your browser opens when you follow the link to buy. The provider of a key in your API Wallet, only when you press Test: OpenAI, Anthropic, Google, OpenRouter, Mistral, Groq, Cohere, Hugging Face, xAI or DeepSeek, each at its own address. Search by meaning: 127.0.0.1, this computer, unless you set an endpoint of your own. That is the whole list for MindToo’s own code; what a connected assistant does with the context you permit follows its own provider and settings. There is no telemetry, no crash reporting and no automatic update, and a test in MindToo’s own source fails if a network call appears anywhere else.

The API Wallet

Your keys, kept.

Where keys live

The API Wallet keeps your API keys with Windows' own encryption, tied to your Windows account. Assistants can see a key’s name, never its value.

Test

A key stays on this computer until you press Test. Then the key goes to its own provider only, in the request’s header, and the test asks for something that costs nothing, such as the list of models. The wallet remembers which keys were working when last tested.
