MindToo

Compared with the alternatives

There are good tools that keep memory for AI assistants, several of them free and open source. This page says plainly what they do, what MindToo does, and where MindToo is the wrong choice. Everything here was checked against each tool’s own documentation on 21 October 2026. If something has changed, tell us: support@privateai.ltd.

In three lines

What MindToo does that the free tools do not.

Nothing to set up first

No terminal, no Node, no Docker, no API key, no account. You run one signed installer. Search by meaning uses a small model that ships inside the app and runs on your computer, so it works before you have added any key, and offline.

It starts with what you already have

It brings in the conversations Claude Code, Codex and Gemini CLI already keep on your computer, and the data exports of the Claude app and ChatGPT. None of the free tools below document an import of your past conversations.

A window to read and correct it

Read, search and correct your memory in one window. A correction replaces the memory for every assistant, and the old version stays in the history. Each assistant gets full, read-only or no access, and a passcode locks the lot.

Fair is fair

Where MindToo is the wrong choice.

You are on a Mac or Linux

MindToo runs on Windows 10 and 11 only. claude-mem, OpenMemory, Memorix and Engrim run wherever their runtimes run; Pieces runs on Windows, macOS and Ubuntu.

You want to read the source

MindToo’s source is not published. The five files of its Claude app plugin, which do the capture there, are public on GitHub, and the memory is one SQLite file you can open with any SQLite tool; the app itself is closed. claude-mem, OpenMemory, Memorix and Engrim are open source under Apache-2.0 or MIT, so anyone can audit what they store and send.

You use assistants MindToo does not cover

MindToo keeps each message and reply in Claude Code, Codex, Gemini CLI, Cursor and Windsurf, and in the Claude app through its skill and plugin. It does not cover Copilot, OpenCode or Antigravity; claude-mem and Memorix do.

You want your memory to follow you between machines

MindToo keeps your memory in one file on one computer, by design, with no account and no MindToo cloud. claude-mem’s paid tier and Supermemory sync through their clouds.

You only use one assistant

Claude Code, Codex and Cursor each have a memory of their own, free and already installed. MindToo earns its place when you use more than one and want them to share what they know.

Tool by tool

What each one is, in its own documentation’s words.

Prices and features are as published by each project on 21 October 2026; follow the links for the current state. We have no connection with any of them.

MindToo

Price and source

Free for 14 days with everything working, then £29 including VAT, paid once, for up to three of your own computers and every 1.x update. Closed source.

Works with

Claude Code, Codex, Gemini CLI, Cursor and Windsurf, and the Claude app.

Where memory lives, and what goes online

One file, mindtoo.db, in the .mindtoo folder in your Windows user folder. It is searched locally by default. Online, MindToo contacts Polar for your licence and a wallet key’s provider when you press Test; if you configure an embeddings server, text is sent to that server. Connected assistants can receive the context you permit.

If you stop paying, or we stop trading

Reading, search and export never lock, even after the trial, and the file is ordinary SQLite.

claude-mem

What it is

An open-source (Apache-2.0) plugin that captures what your agent does during sessions, compresses it with an AI model and injects relevant context into future sessions. It works with Claude Code, Codex, Gemini, Copilot, OpenCode and others, and has a web viewer. It needs Node 20 or later, Claude Code with plugin support, Bun and uv, and a local worker. The compression step runs through an AI provider: your own Anthropic plan or key, or its hosted service, which is free for 30 days and then $30 a month. It does not document an import of past conversations. claude-mem on GitHub; its hosted tier.

OpenMemory, by Mem0

What it is

An open-source (Apache-2.0) local memory server that speaks MCP, with a dashboard to add, browse and delete memories and to control which client may read them. It works with Cursor, Claude Desktop, Windsurf, Cline and other MCP clients. It runs as a Docker container and needs an OpenAI API key; Mem0 says the memory store stays on your machine, and the memory extraction uses OpenAI’s models by default. Mem0’s hosted platform runs from a free tier to $249 a month. OpenMemory documentation; Mem0 pricing.

Memorix

What it is

An open-source (Apache-2.0) local-first shared memory for AI coding agents over MCP, with SQLite as its store and a web dashboard and terminal interface. It covers Claude Code, Codex, Cursor, Windsurf, Gemini CLI, Copilot and more. It needs Node 22.18 or later and Git; API keys and sync are optional, and nothing is sent anywhere by default. Memorix on GitHub.

Engrim

What it is

An open-source (MIT) local memory engine for AI command-line tools, installed with pip, keeping one SQLite file with local embeddings and no telemetry or cloud sync. It connects to Claude Code through hooks and to Cursor and Windsurf through MCP. It has no window of its own. Engrim on GitHub.

Supermemory

What it is

A cloud memory service with plugins for Claude Code, Cursor and Codex. The free tier gives $5 of credits a month; paid plans run from $19 to $399 a month. A self-hosted binary exists under a "lite" licence, and Supermemory says its server source is not in the public repository. Memories go to Supermemory’s cloud unless you self-host. Supermemory pricing; self-hosting.

Pieces

What it is

A desktop app for Windows, macOS and Ubuntu whose long-term memory watches your clipboard, screen, audio and application activity and keeps the result on your device, with MCP access for nineteen clients including Claude Code, Claude Desktop, Codex CLI, Gemini CLI, Cursor and Windsurf. There is no free tier: $18.99 per user a month after a 7-day trial. Prompts sent to cloud models carry your immediate context; telemetry can be turned off. Pieces pricing; Pieces on your data.

The memory built into Claude Code, Codex and Cursor

Claude Code

Two kinds, both free: CLAUDE.md files you write, and auto memory, notes Claude Code writes for itself, kept per repository as plain markdown files on your machine. Neither is shared with other tools or other machines. Claude Code memory documentation.

Codex

Local Codex clients keep a separate local memory store, off by default, generated in the background from your chats into files under your Codex folder; they are not meant to be edited by hand and there is no viewer. Codex memories documentation.

Cursor

Memories are rules Cursor generates from your chats, kept per project and per user and managed in its settings. Cursor’s documentation does not say where they are stored. Cursor Memories documentation.
